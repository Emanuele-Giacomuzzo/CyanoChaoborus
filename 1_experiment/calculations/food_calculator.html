Daphnia food calculator

Purpose

Calculate how much phytoplankton to mix to obtain the desired carbon ratio between different species.

quarto render calculations/food_calculator.qmd
$$ \[\begin{array}{l} M_{P}^{\mathrm{jar}} = D_P \times V_J \\[8pt] M_{P}^{\mathrm{tot}} = M_{P}^{\mathrm{jar}} \times n_J \\[8pt] n_J = \text{number of jars} \\[2pt] V_J = \text{volume of one jar} \\[2pt] D_P = \text{phytoplankton density} \\[2pt] M_{P}^{\mathrm{jar}} = \text{phytoplankton mass per jar} \\[2pt] M_{P}^{\mathrm{tot}} = \text{total phytoplankton mass} \end{array}\]

$$

M = mass (only C)

V = volume

n = number

D = density

Input: - Number of Daphnia cultures - Optical density of the Synechococcus sample - Optical density of the Tetradesmus sample - Optical density of the Microcystis sample - Optical density of the Nannochloropsis sample

Output: - Volume of Microcystis - Volume of Synechococcus - Volume of Nannochloropsis - Volume of Tetradesmus - Volume per Daphnia jar Microcystis + Tetradesmus - Volume per Daphnia jar Synechococcus + Tetradesmus - Volume per Daphnia jar Nannochloropsis - Volume of mix Microcystis + Tetradesmus - Volume of mix Synechococcus + Tetradesmus - Volume of Nannochloropsis

The app’s parameters (jar volume, target carbon concentration, and each species’ OD-to-carbon calibration) are not typed in below by hand. A standalone Shinylive app like this one runs client-side in the reader’s browser and has no access to this document’s R session or to the repository’s data files, so instead the code block is generated at render time from calculations/food_calculator_parameters.csv — a snapshot written by 5a_calculations_OD.qmd from the live calibration fit. Re-rendering the master document (or just 5a_calculations_OD.qmd) refreshes that snapshot; re-rendering this file then bakes the refreshed numbers into the app below.

        step = 0.01
      ),
      numericInput(

      ),

server <- function(input, output) {

  ## Baked in from calculations/food_calculator_parameters.csv at render time
  ## (see the Purpose section above for why these are not read live).
    Large_jar_liquid_litres <- 0.8
    Daphnia_algae_C_ad_libitum_mg_per_L_per_day <- 2
    extra_food_percentage <- 25
    Phyto_low_quality_food_ratio <- 0.5
    Tetradesmus_OD_to_C_slope <- 158.32
    Tetradesmus_OD_to_C_intercept <- -10.991
    Synechococcus_OD_to_C_slope <- 89.419
    Synechococcus_OD_to_C_intercept <- -4.463
    Microcystis_OD_to_C_slope <- 120.147589554584
    Microcystis_OD_to_C_intercept <- -0.405178209732212
    Nannochloropsis_OD_to_C_slope <- 96.7264952720823
    Nannochloropsis_OD_to_C_intercept <- 0.427886502870943

  output$parameters_echo <- renderTable({
    data.frame(
      Parameter = c("Large_jar_liquid_litres", "Daphnia_algae_C_ad_libitum_mg_per_L_per_day",  "extra_food_percentage", "Phyto_low_quality_food_ratio", "Tetradesmus_OD_to_C_slope",  "Tetradesmus_OD_to_C_intercept", "Synechococcus_OD_to_C_slope",  "Synechococcus_OD_to_C_intercept", "Microcystis_OD_to_C_slope",  "Microcystis_OD_to_C_intercept", "Nannochloropsis_OD_to_C_slope",  "Nannochloropsis_OD_to_C_intercept"),
      Value = c(0.8, 2, 25, 0.5, 158.32, -10.991, 89.419, -4.463, 120.147589554584,  -0.405178209732212, 96.7264952720823, 0.427886502870943)
    )
  })

  ## Placeholder until the actual mixing calculations are implemented.
  output$outputs_single_echo <- renderTable({
    data.frame(
      Species = c("Microcystis", "Synechococcus", "Nannochloropsis", "Tetradesmus"),
      Value = 0
    )
  })

  output$outputs_mix_echo <- renderTable({
    data.frame(
      Mix = c("Microcystis + Tetradesmus", "Synechococcus + Tetradesmus"),
      Value = 0
    )
  })

  output$outputs_jar_echo <- renderTable({
    data.frame(
      Mix = c("Microcystis + Tetradesmus", "Synechococcus + Tetradesmus", "Nannochloropsis"),
      Value = 0
    )
  })
}

shinyApp(ui, server)
