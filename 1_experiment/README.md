# The interactive effects of toxicity and poor food quality of Cyanobacteria via indirect effects on Chaoborus

For the background and motivation behind this project, see the [project README](../README.md).

## Folder layout

Everything lives flat in this folder with a sequential number prefix, so a plain `ls` shows the full reading/reference order at a glance. The book chapters and the protocols appendix are stitched into one document; the protocols themselves live one level down, in [protocol/](protocol/).

### The book

**[Rendered_files/Rendered.html](Rendered_files/Rendered.html) is the whole introduction, design, calculations, and protocol write-up rendered as a single document** — download and open it if you want the current state of the plan (it has a navigable sidebar and collapsible code sections).

It's generated from the Quarto master file `1_master.qmd`, which stitches the chapters below together (via `{{< include >}}`) in reading order. Each chapter is its own small file so edits stay easy to review; only `1_master.qmd` needs to change if you want to reorder chapters. These are source files, not meant to be read directly on GitHub — they contain raw Quarto/R syntax that only renders correctly through the build step below, so always read the rendered HTML instead:

- `2_overview.qmd` — project introduction (includes the repo's top-level [README](../README.md)), plus background and hypotheses
- `3_parameters.qmd` — sourced numeric assumptions (biomass, weights, growth times, biodilution factors) shared by the chapters below
- `4_calculations.qmd` — organism, jar, and infrastructure quantities, computed (not hand-typed) from `3_parameters.qmd`, and quoted inline throughout the chapters below
- `5_experimental_design.qmd` — treatments, Chaoborus setup, and end points
- `6_experimental_procedure.qmd` — pre-experiment culturing and assembly steps
- `7_bibliography.qmd`
- `8_protocols.qmd` — appendix, auto-generated from every Markdown file in [protocol/](protocol/), included in full at the very end of the book

**To rebuild the rendered files after editing any chapter**, run from this folder:

```sh
quarto render 1_master.qmd
mkdir -p Rendered_files
mv 1_master.md Rendered_files/README.md
mv 1_master.html Rendered_files/Rendered.html
```

If accented characters or emoji come out garbled (e.g. `<e2><80><94>` instead of `—`), your shell locale isn't UTF-8 — rerun `quarto render` with:

```sh
LANG=en_US.UTF-8 LC_ALL=en_US.UTF-8 quarto render 1_master.qmd
```

### Protocols

Stand-alone bench SOPs, one canonical protocol per procedure (superseding the older dated-log versions logged on different days). They're included in full as an appendix at the end of [Rendered_files/Rendered.html](Rendered_files/Rendered.html), but each one is still meant to be opened and read on its own at the bench, not as part of a start-to-finish read of the book.

- [1_create_COMBO.md](protocol/1_create_COMBO.md) — preparing COMBO growth medium
- [2_create_Zoo-COMBO.md](protocol/2_create_Zoo-COMBO.md) — preparing Zoo-COMBO medium *(to be written)*
- [3_create_Daphnia_jars.md](protocol/3_create_Daphnia_jars.md) — setting up *Daphnia* culture jars
- [4_feed_Daphnia.md](protocol/4_feed_Daphnia.md) — feeding *Daphnia* cultures
- [5_create_Chaoborus_jars.md](protocol/5_create_Chaoborus_jars.md) — setting up *Chaoborus* jars
- [6_sample_phytoplankton.md](protocol/6_sample_phytoplankton.md) — sampling phytoplankton
- [7_sample_Daphnia.md](protocol/7_sample_Daphnia.md) — sampling *Daphnia* *(to be written)*
- [protocol/to_be_sorted/](protocol/to_be_sorted/) — protocols not yet folded into the canonical list above (sample collection/storage, end-of-experiment sampling)
- [protocol/old_redundant/](protocol/old_redundant/) and [protocol/quarto/](protocol/quarto/) — superseded dated protocol versions (`.docx` originals and their Quarto conversions), kept for reference

## Everything else

- [Rendered_files/](Rendered_files/) — the rendered book (`README.md` and `Rendered.html`), regenerated by `quarto render` (see above)
- [calculations/](calculations/) — the original spreadsheet (`All_calculations.xlsx`) and its messy narrative draft (`Specific_calculations.md`) that `4_calculations.qmd` supersedes, kept for reference until fully retired; and [food_calculator.html](calculations/food_calculator.html), a self-contained Shinylive app (source: `food_calculator.qmd`) for computing daily *Daphnia* feeding volumes from OD readings — runs entirely in the browser, no R server needed. Re-render it after editing the source: `quarto render calculations/food_calculator.qmd`
- [media/](media/) — embedded images extracted from protocol source documents
- [Figures](figures/) — source image files for the figures used in the design chapter
