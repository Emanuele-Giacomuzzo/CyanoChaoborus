# Project board

A lightweight, at-a-glance view of what's open, what's underway, and what's done across the project. This is a plain checklist — no app, no login, no dependency on anything else in the repo.

**How to use it:**
- Move an item between sections as its status changes, or just flip `[ ]` to `[x]` and leave it under "Done".
- Add new items under "To do" as they come up — no fixed format required, just enough detail that anyone on the team understands it.
- Tag each item with the stage it belongs to (`[Experiment]`, `[Data]`, `[Analysis]`, `[Results]`, `[Other]`) so it's easy to scan for what's relevant to you.
- Detailed, science-specific open questions (e.g. a parameter that needs confirming) can stay inline in the relevant `.qmd` file's own "To do" note — use this board for items worth tracking at a glance across the whole project, not a duplicate of every inline comment.

**If this isn't working for the team:** delete this file. Nothing else in the repo links to or depends on it.
