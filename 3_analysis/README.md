# Analysis

Standalone analyses that turn raw or processed data into results used elsewhere in the project.

- [OD_curves_calculation.qmd](OD_curves_calculation.qmd) — fits the OD-to-carbon calibration curves for *Microcystis aeruginosa* and *Nannochloropsis limnetica*, used to convert a culture's optical density into the carbon dose needed to feed *Daphnia* and *Chaoborus* consistently across diets.
